# MicroSaaS-para-professores
A ideia é criar um sistema que ajude os professores a criarem provas mais facilmente, para isso, os professores poderão armazenas questões que ja ultilizaram em algum momento e posteriormente, filtrando por: matéria e dificuldade; poderão gerar provas automaticamente.

Sobre o Projeto:
  Esse projeto é o meu primeiro contato real com o verdadeiro desenvolvimento de sistemas (Back-End), nele pude aprofundar mais os meus conhecimentos em POO e na linguagem C#; aprendendo sobre o Framework ASP.Net

Tecnologias:
  Back-End:
    *Linguagem: C#
    *Framework: ASP.Net
  Front-End:
    *Foi ultilizado a Inteligência Artificial do Cursor (editor de codigo) para fazer o front-end

Conceitos Aplicados:
  *Arquitetura: Programação Orientada a Objetos (POO)
  *Clean Code: Foco em código legível e manutenível

Funcionalidade em funcionamento:
  *Cadastro de Usuario
  *Sistema de login
  *Guardar questões
  *Ver banco de questões

Funcionalidades a serem implementadas:
  *Gerador de prova
  *Exportação (formatação de documentos prontos para aplicação)
  *Página de perfil

Como Executar:
  1 - Tenha o .NET SDK instalado
  2 - Clone o repositório
  3 - Execute o projeto com o comando: dotnet run

Aprendizado obtido:
  *ASP.Net core
  *Entendimento sobre controllers e models
  *Aprofundamento de conhecimentos na área de back-end, POO e tecnologia C#
